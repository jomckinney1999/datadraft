# SQL Sports

Learn SQL and data analytics through fantasy football.

See [docs/PLAN.md](docs/PLAN.md) for the product/pricing plan and the reasoning behind it.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
